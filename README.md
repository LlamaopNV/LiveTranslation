# LiveTranslation

Real-time bidirectional speech translation system with voice cloning, powered by GPU acceleration.

## Overview

LiveTranslation is a real-time translation system that enables seamless communication between English and German speakers. The system features:

- **English → German**: Speak in English, get real-time German audio output in your own voice
- **German → English**: Listen to German audio and receive English translation (voice or text)
- GPU-accelerated processing using NVIDIA RTX 5080 for minimal latency
- Voice cloning technology to maintain natural speech patterns
- Configurable audio input/output device selection

## Key Features

### Bidirectional Translation
- **Mode 1 (English → German)**:
  - Capture English speech via microphone
  - Real-time translation to German
  - Voice-cloned audio output in your voice template

- **Mode 2 (German → English)**:
  - Capture external German audio
  - Real-time translation to English
  - Output as voice or text

### Performance
- GPU-accelerated inference (RTX 5080)
- Optimized for low latency and lossless quality
- Real-time processing pipeline

### Audio Control
- Selectable input audio devices
- Selectable output audio devices
- Support for various audio interfaces
